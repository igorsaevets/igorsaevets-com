I build open-source developer tooling for the step nobody enjoys: getting a web page into a language model without the navigation, cookie banners and boilerplate coming along with it.

Page2AI is that work. It converts any web page to clean Markdown and ships as a Chrome extension, a Firefox add-on, a Model Context Protocol server for AI agents, and npm libraries. Everything runs locally, sends nothing to a server, is MIT-licensed, and is free and stays free. The extraction quality is measured against other tools in a public benchmark that anyone can re-run, including the cases where Page2AI loses.
